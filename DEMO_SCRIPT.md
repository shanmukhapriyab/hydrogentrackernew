# Hydrogen Tracker — Demo Script (Maximum 3 Minutes)

Record the actual application running locally or on a deployed URL. Keep the screen recording under 3:00. Do not show passwords, API keys, private customer details, or confidential data.

## Suggested timing

- **0:00–0:20 — Introduction:** State the problem: hydrogen production, storage, shipment, and delivery information can be scattered across separate workflows. Introduce Hydrogen Tracker as a centralized tracking dashboard.
- **0:20–0:45 — Dashboard:** Show the role-appropriate dashboard and summarize the operational information visible.
- **0:45–1:10 — Production and storage:** Open production records, then the storage page. Demonstrate the Add Tank form with sample data, save it, and show where the new tank/report/record appears. Only describe the behavior that actually works in the current build.
- **1:10–1:35 — Shipments and deliveries:** Show a sample shipment and its delivery status. Explain how the records help follow movement through the workflow.
- **1:35–2:00 — Map and notifications:** Show the map and explain what its markers represent in the current implementation. Trigger or show an existing sample notification if available; do not claim live GPS or real-time alerts unless tested.
- **2:00–2:25 — Analytics and customers:** Show the forecast/chart and customer page. Briefly explain the data being displayed.
- **2:25–2:50 — Technology and value:** Mention React/Vite, Express/Node.js, MongoDB, and Socket.IO if present in the current code. Close with the benefit: a consolidated view of hydrogen operations.
- **2:50–3:00 — Closing:** Show the project name and repository URL.

## Upload and link
1. Record the walkthrough using a screen recorder.

3. Upload to YouTube as Unlisted or to Google Drive with viewer access enabled.
